На этой неделе UI усложняется: пройдет лекция по Compose, после которой можно будет доработать написанное ранее, и реализовать более сложное поведение. Также связываем экраны с данными из сети. Продолжим в следующем домашнем задании после соответствующей лекции.

**Часть 1. Доработки в UI**

* Сделать экран “Аналитики” с использованием Jetpack Compose. Периодом по умолчанию является период от начала текущего месяца до текущей даты. Список внутри истории должен быть отсортирован от недавних транзакций к более поздним. Должны быть реализованы различные фильтры, как на макетах в фигме.
* Доработать UI из предыдущего задания в соответствии с полученными на этой неделе знаниями.

**Часть 2. Работа с сетью**

Нужно реализовать сетевой слой для реализованных ранее экранов:

* Расходы

* Доходы

* Список счетов

* Аналитика

При этом работу с данными нужно будет сделать асинхронной, если это не было заложено ранее – получение списков расходов/доходов/истории через suspend и/или Flow и подобное.

**Часть 3. Объединение UI и работы с сетью**

Нужно продумать и реализовать состояния UI:

* Loading (пока «загружаем»).

* Content.

* Empty.

* Error.

После этого все реализованные ранее экраны должны получать данные из сети и корректно отображать все перечисленные состояния.

### **Требования**

UI

* Не должно быть «бизнес-логики» внутри @Composable функций (минимум: вынести в отдельные классы/вью-модели/холдеры состояния).
* Состояния экрана «Аналитика» отрисовываются корректно.
* Сортировка и дефолтный период реализованы корректно.
* Используются лучшие практики из лекции по Compose.
* Не должно быть зависаний/крашей при переключении вкладок и открытии/закрытии экранов.

Network

* Походы в сеть не происходят в рамках главного потока.
* Вся бизнес логика происходит не на главном потоке.
* Реализованы необходимые сетевые модели, а также соответствующие доменные модели для необходимого функционала.

UI \+ Network

* Нет использования сетевых моделей для отрисовки UI и бизнес-логики приложения.

* Данные на всех экранах получаются из сети.

* Корректно обрабатываются все состояния работы с данными на всех экранах.
